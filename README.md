# DataBaseGo

Учебная база данных на Go с хранением таблиц в CSV-файлах. Запросы вводятся в терминале на простом языке команд SQUIRTSQL.

Проект позволяет создавать таблицы, добавлять записи, читать их, обновлять и удалять по ID. Используется только стандартная библиотека Go.

## Запуск

В `go.mod` указана версия Go **1.27.2**. Проверь установленную версию:

```bash
go version
```

Открой терминал в папке проекта и запусти:

```bash
go run .
```

После появления `>>` вводи команды по одной строке. Файлы таблиц создаются в текущей рабочей папке: таблице `users` соответствует файл `users.csv`.

Для выхода нажми `Ctrl+C` или заверши ввод: в Linux и macOS — `Ctrl+D` на пустой строке.

## Пример работы

Введи команды последовательно:

```text
CREATE_TABLE users id name age
INSERT users Андрей 25
INSERT users Мария 30
SELECT users
```

Результат выборки:

```csv
id,name,age
1,Андрей,25
2,Мария,30
```

Обновление и выборка одной записи:

```text
UPDATE users 1 Андрей 26
SELECT users 1
```

Результат:

```csv
1,Андрей,26
```

Удаление записи:

```text
DELETE users 2
```

## Команды

| Команда | Формат | Назначение |
| --- | --- | --- |
| `CREATE_TABLE` | `CREATE_TABLE table id column [columns...]` | Создать таблицу с заголовками |
| `INSERT` | `INSERT table value [values...]` | Добавить запись с автоматически созданным ID |
| `SELECT` | `SELECT table` | Вывести таблицу целиком, включая заголовки |
| `SELECT` | `SELECT table ID` | Вывести одну запись без заголовков |
| `UPDATE` | `UPDATE table ID value [values...]` | Заменить все значения полей записи, сохранив ID |
| `DELETE` | `DELETE table ID` | Удалить запись |

Квадратные скобки в описании формата обозначают необязательную часть; вводить их не нужно.

Правила запросов:

- Команды пишутся заглавными буквами.
- Аргументы разделяются пробелами или табуляцией. Разделяющие запятые не нужны.
- Имя таблицы указывается без расширения `.csv` и без пути к файлу.
- Первый столбец обязательно называется `id`. Названия колонок не должны повторяться.
- При вставке и обновлении передаются значения всех колонок, кроме `id`, в порядке заголовков.
- ID — положительное целое число без знака и ведущих нулей. При вставке его указывать не нужно.
- Повторное создание существующей таблицы завершается ошибкой и не перезаписывает файл.

## Как устроен проект

| Файл | Назначение |
| --- | --- |
| `main.go` | Чтение команд из терминала и вывод результата |
| `query.go` | Разбор, проверка и выполнение команд |
| `db.go` | Чтение и изменение CSV, проверка таблиц и генерация ID |
| `db_test.go` | Тесты операций с таблицами и одновременных вставок |
| `query_test.go` | Тесты разбора запросов и выполнения команд |

При вставке, обновлении и удалении результат записывается во временный файл в папке таблицы. После успешной записи и закрытия он заменяет исходный файл. Мьютекс защищает операции от одновременного выполнения внутри одного процесса.

## Проверка проекта

Запускай команды из папки проекта:

```bash
go test ./...
go test -cover ./...
go test -race ./...
go vet ./...
```

Проверка с `-race` требует поддержки детектора гонок в установленной среде Go.

## Ограничения

- Парсер делит запрос по пробельным символам. Значения с пробелами, пустые значения и экранирование через кавычки пока не поддерживаются.
- Все значения хранятся как строки; типы колонок не задаются.
- Следующий ID вычисляется как максимальный существующий ID плюс один. После удаления записи с максимальным ID её номер может использоваться повторно.
- Операции изменения читают и перезаписывают таблицу целиком, поэтому проект рассчитан на небольшие файлы.
- Блокировка действует только внутри одного процесса. Одновременная запись несколькими экземплярами программы не поддерживается.
- Поддерживаются только перечисленные команды: фильтрации по другим колонкам, сортировки, связей между таблицами и транзакций пока нет.
